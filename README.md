## Overview

Proyek ini bertujuan memprediksi biaya medis tahunan pasien menggunakan regresi *machine learning* berdasarkan dataset Kaggle (*Medical Insurance Cost Dataset* oleh Mohan Krishna Thalla, mencakup 100.000 data individu di Amerika Serikat dengan rentang tahun 2015–2024) guna membantu perusahaan asuransi kesehatan memperkirakan biaya tagihan medis nasabah (sebagai pertimbangan penetapan premi) dengan presisi dan mencegah kerugian finansial.
